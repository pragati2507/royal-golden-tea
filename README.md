# Royal Golden Mix Tea

A premium, mobile-first product landing page built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Milestone 1

Includes the hero, product overview, bundle cards, benefits, preparation guide, FAQ, contact area, footer, WhatsApp action, and a sticky mobile order button. Commerce, payments, databases, and administration are intentionally out of scope.
